# Технологический радар компании «Будущее 2.0»

Данный радар отражает стратегию технологической трансформации IT-ландшафта «Будущего 2.0» на горизонте 12 месяцев: переход от монолитного DWH (MS SQL Server 2008) и старой шины ESB к облачной доменной архитектуре (Data Mesh / Lakehouse) в Yandex Cloud с запуском портала самообслуживания.

* **Adopt** — целевой стек, обязательный к применению во всех новых проектах.
* **Trial** — технологии, проходящие пилотное внедрение в отдельных доменах.
* **Assess** — перспективные инструменты для интеграции будущих партнёров (фармацевтики и производителей электроники).
* **Hold** — легаси-системы, в которые запрещено добавлять новую бизнес-логику (вывод из эксплуатации).
